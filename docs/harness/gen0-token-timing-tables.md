## 读法

1. **视觉臂"时间贵、token 贱"**：glm 全场 78 万入 + 49 万出 tokens（< DeepSeek 输入的 0.2%），却占 4.2 h ≈ 全场计算时间的 20%——单次 19.7 s 的推理延迟才是它的真实成本；砍视觉调用次数省的是墙钟不是钱。
2. **98% 缓存命中**：逐回合追加式对话结构让 627M 输入的绝大部分按缓存价计费。
3. **每 turn 输出 ~1400 tokens 恒定**（各 suite 1100–1500）：推理量与任务难度无关；难任务贵在 turn 数与上下文规模（10 系入/turn 183k vs spatial 的 82k）。
4. **18 s/turn 的大致构成**：DeepSeek 生成 ~1400 tok（约 10–13 s）+ 视觉摊销（~3 s）+ 工具执行与仿真（~2–4 s）。
5. **失败的时间成本是成功的 3 倍**：24 个失败格吃掉全场 57% 的时间（几乎全程磨到预算顶）——早期止损机制（感知预算、no_feasible 快判）的时间价值所在。
