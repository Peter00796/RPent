# RPent-harness 论文方向定稿备忘录

写给项目负责人。输入是四篇对手论文的完整卡片(ETA/OpenETA、ASPIRE、上游 Harness VLA、CaP-X)、我们的五条候选论点(T1–T5)、以及对抗检索的逐条判决。下面是综合结论。

---

## 〇、先说总判断

"别人做 agent 框架、没人做 harness 框架"这个原始定位**站不住**。ETA 就是一篇 harness 论文(宿主门控、回执认证、MCP 沙箱、预注册清单),而且我们 fork 的上游连名字都叫 Harness VLA。定位只有下沉一层才成立:四家的 harness 都在**管执行**(权限、安全、审计、重放)或**堆性能**(记忆、技能、重试),没有一家把 harness 当**测量仪器**用——没有一家量过自己的复现噪声,没有一家把"agent 知道什么/能调什么"做成代码强制的实验臂,因此没有一家能说清"哪个部件导致了哪个结果、置信度多少"。我们的论文应该整篇站在这一层,而且必须靠**结论**站住,不能靠**功能清单**站住——对抗检索已经证明,五条论点里所有"我们第一个做了某机制"的说法全部被打穿,活下来的都是"我们测出了某个别人测不出的结果"。

## 一、幸存论点排序(强到弱,附收窄后的表述)

### 第 1 名:T3 —— 知识放置规则(记忆迁移二分 + "该进工具的不进记忆")

**幸存原因**:这是唯一一条"负结果 + 正结果 + 可证伪规则 + 干预验证"四件齐全的论点,而且文献里确认存在空白——Externalization 综述(2604.08224)明确说分层结构有定义、**分配准则**没有。

**必须先截肢两处**:(a) "第一个证明通用记忆不迁移"——不成立,MTL(2604.14004)、2605.23899、EvoAgentBench(2607.05202)到 2026 年中已把这个负结果变成领域共识;(b) "把经验沉成工具是我们的发明"——不成立,Voyager、SkillWeaver 早就做了,只是它们**什么都沉**,没有准则。

**收窄后的表述**:已有工作分别证明了自动萃取的通用记忆常常不迁移、以及经验可以沉淀成可调用工具,但没有工作陈述并检验"哪类知识该放哪一层"的准则。我们贡献第一条显式、可证伪的放置规则——**随实例变化 且 可由工具计算 ⇒ 放进工具,不放进记忆**——并做第一个干预式检验:在记忆形态为唯一操纵变量、配对且噪声已标定的设计里(53 格配对,10 种子考试),通用规则库与噪声不可区分(40 vs 34/34),任务限定 playbook 把成功率提高三倍(约 1/3 → 6/10 与 9/10);按规则前瞻地把 playbook 里的抓取几何条目(本质是 LLM 在脑内做抓取合成的缓存输出)沉入 plan_grasp 工具,并证明相应记忆条目变得冗余。该规则还能不加事后拟合地回溯解释领域两类已发表的失败:ETA 的候选全被门拒(它的架构里 Skill 是因果惰性文本、连存世界坐标都被禁止,随实例变化的可计算知识**无处合法安放**),以及 ASPIRE 的入库后腐坏(知识存在了计算它的层之上)。负结论的范围要收窄到"基准内任务成绩",不涉及跨域抽象洞见的迁移(MTL 证明那是能成的)。

**审稿风险与堵法**:规则目前是回溯式的、近乎同义反复——"可由工具计算"是事后判的。要变成科学,必须(i)对一批留出的候选条目**先分类、后测迁移**,预测每条的命运;(ii)给两个谓词一个机械或多人一致的操作化定义。另外要解释为什么我们的 playbook 打到 9/10 而 ETA 的 exact-task playbook 只有 1/30:我们的做符号化再落地(re-ground),他们的逐字重放、构造上零泛化——这个对比本身是给 T3 加分的素材,要写进正文。

### 第 2 名:T4 —— 带机理和治法类别的"墙"分类学

**幸存原因**:单看"分类学给出治法而非终止标签"不新——Model-or-Harness(2607.28802)已做故障侧→治法映射,MAST 已做分类学引导的干预并测了增量,RoboFAC 在机器人域已有带验证修正的失败分类,而且整个方法论就是 1992 年的正交缺陷分类(ODC)。但**三件事的合取**没有先例:(1) 具身操纵域、每类带定量物理签名(抓取 ~37%/次;checker 容差 ±1-2cm vs 开环释放 ±2cm;缺 roll 自由度);(2) **每类**一个不同的治法预测,且被执行、被证实或证伪(RoboFAC 是一个万能修正器套所有类;Model-or-Harness 只断言不执行);(3) 类别由跨臂反事实定义("playbook 可治""两臂皆不可解"),单臂 harness 根本定义不出来——这使分类学成为 T1/T2 仪器的下游产物,也是四家谁都造不出它的结构性原因。

**收窄后的表述**:我们贡献第一个干预验证的具身操纵 harness 因果失败分类学:每个墙类由定量跨臂签名操作化,每类携带一个治法类别预测(playbook / 新原语 / 无解),我们执行预测的干预并报告证实或证伪结果;表达力墙不靠归纳而靠可达性论证(原语代数里没有 roll 自由度和 guarded move,旋转门轨迹**构造上不可达**——这是全文唯一可证明而非采样的部分,必须写成证明)。诚实定位:这是 ODC 方法论移植到物理 agent harness 并做逐类治法验证,引用 Chillarege 1992,不要藏。

**审稿风险与堵法**:四个类从一个 harness、两个臂上事后归纳出来,现在是项目回顾录不是科学分类学。必修:(i)下一代实验**先登记**墙标签再跑治法,报出样本外预测准确率;(ii)给分派规则做评分者一致性(MAST 报了 κ=0.88,我们现在是零);(iii)报一个 playbook 治不好的"语义墙"作证伪案例,证明类别不是同义反复。

### 第 3 名:T2(收窄版)—— 委托式能力剪枝:加工具让系统在某格上严格变差,且机理可归因

**必须放弃的部分**:"机械化工具消融是我们的仪器"——被两次打穿:SWE-agent(2024)早就在固定 agent、固定任务集上逐工具消融并归因到百分点;VoLo(2606.07723)在**一模一样的具身 VLA-as-tool 场景**做了 No-VLA / Only-VLA 臂。"只有配对消融臂才能发现"也不成立——SAFE/VLA-FAIL 这类运行时检测器就是为"VLA 静默失败"而生的,它们**能检出**失败的 episode;消融臂独有的是**反事实归因**(工具的存在导致该格不可解),论点必须把检测与归因分开。

**幸存的核心**:没有任何已定位的先行工作报告过这个机理——一个冻结的学习原语,其训练分布边界排除了唯一可行的策略类,失败时返回值里无任何信号,而规划器的委托行为封死了无工具臂本会执行的替代策略——并做出配对的、到单个具名工具的伤害归因。VoLo 报的是反向结果(全系统处处占优),SHAPER 的回归归因不到单个技能。t7 是文献里没有的东西:**加一个工具让系统在配对格上严格变差,机理是能力边界静默否决**。

**收窄后的表述**:我们报告工具添加单调性的一次违背及其未被记录过的机理——委托式能力剪枝:配对种子下,给 agent 配上冻结 VLA 使 t7 格从可解变为不可解;VLA 的训练分布不含卧姿物体抓取,失败无信号,规划器的委托封死了纯 LLM 臂实际执行的策略;我们通过隔离探测 VLA 验证边界属于工具而非 episode,并在 N 个种子上复现反转。运行时失败检测器能标记 episode,不能归因到工具的存在;配对消融臂提供了把静默的逐 episode 失败变成逐工具因果伤害归因的反事实。

**硬条件**:隔离探测和多种子复现**不跑就不能写**。现在 t7 是一个格、一次观察,是插在工程 flag 里的轶事。这两件事跑完,T2 是全文最锋利的单点发现;跑不完,降级为 T4 里表达力墙的一个例证。

### 第 4 名:T1(收窄版)—— 不再单独成论点,降为方法论骨架

作为"第一个……"的论点已死(见杀名单)。但收窄后的两个可测主张仍有价值,而且是 T3/T4 可信度的地基:(1) 臂完整性是**可验证属性**——文件访问边界代码强制、每次运行指纹化,"记忆臂有没有偷看考试种子"回答靠机制不靠承诺;(2) 我们自测的 ±4-5 格单次总分噪声,恰好把可比系统(四家全部零误差棒)常规报告的单次增量置于检出阈附近——gen-0 的 −6 若无噪声底就会被随意发表成"记忆有害"或"记忆无用"。这两条写进方法章和一个"仪器改变结论"的小节,不做标题论点。前提是把噪声底从两个点补成分布(再跑 3-5 次复现),否则连方法章都撑不稳。

## 二、推荐的论文主轴

**主轴 = T3 放置规则为主张,T2 机理发现为最锋利证据,T4 分类学为组织框架,T1 收窄版为方法论地基。** 一句话主标题方向:*经验知识该放哪一层:具身 agent harness 中记忆、工具与能力边界的因果归因*。

**主claim**:经验衍生的知识有正确的存放层;放错层会以两种对称方式失败——该沉入工具的知识存成文本记忆则不迁移(gen-0 负结果、ETA 全拒、ASPIRE 腐坏),而工具自身的能力边界若不可见,则委托本身会剪掉可行策略(t7)。判定层的准则是可陈述、可证伪、可干预验证的。

**三个已测支撑结果**:
1. 配对 53 格、噪声标定下,通用规则库不迁移(40 vs 34/34,两种库形态),而任务限定 playbook 三倍提升(~1/3 → 6/10、9/10);
2. t7 反转:纯 LLM 臂可解、VLA 臂不可解,根因追到 VLA 拒抓卧姿物体且返回无信号——工具伤害的存在性证明;
3. 墙分类学的定量签名与已执行的治法:语义墙被 playbook 治愈(即结果 1 的考试格)、运动彩票 ~37%/次、精度失配 ±1-2cm vs ±2cm、旋转门两臂皆败(表达力墙,配可达性论证)。

**封口所缺的一个实验**(全文性价比最高,必须排最前):**plan_grasp 已装、playbook 撤掉的臂,在被沉降的格上追平或超过 playbook 臂**。这一个结果把放置规则从格言变成已验证机制,同时把"工具沉降"闭环。第二优先:t7 的 VLA 隔离探测 + 多种子复现(T2 的生死线)。第三优先:补 3-5 次复现跑,把噪声底做成分布。这三件事按成本排,第一件最便宜、价值最高。

## 三、该让的地(诚实引用,不竞争)

- **ETA/OpenETA**:治理与审计是他们的地盘——回执认证的 reward、预注册冻结清单、D/Q/R/H 四门、诚实发表的全负自进化结果。我们没有预注册文档,他们有,审稿人会看到这个不对称。引用他们的"No candidate passes all promotion gates"作为 T3 规则的**领域级验证数据点**,把他们的负结果变成我们的证据,而不是比谁的门多。
- **ASPIRE**:技能积累与进化搜索是他们的地盘,规模和 baseline 覆盖我们追不上。种子分离的协议意图他们先有(debug 51-65 / eval 1-50);我们只主张"协议纪律 vs 代码强制"的区别,且除非测出泄漏量,连这个都别夸大。他们 §5 自认的"stale, overly specific, redundant, or misleading"直接引用,作为 T3 的第二个领域级验证点。
- **上游 Harness VLA**:整个 VLA-as-primitive 架构、固定原语词表、bootstrap/部署分离都是继承来的,论文要明说我们是它的 fork 与扩展,差异只在仪器层。它的 Table 5 崩塌(87%→31% zero-shot)也是 T3 二分的旁证,引。
- **CaP-X**:S1-S4 阶梯确实先做了"变 API 面测依赖"的事;我们的区别只在"固定 agent 内、配对格上、归因伤害",不在"变工具面"本身。
- **方法论祖先,必须引不能藏**:统计——PhAIL(具身域 McNemar+CI 先做了)、Miller 2411.00640、TRI;记忆退休——ExpeL、MemoryBank、Mem0;工具消融——SWE-agent、VoLo;分类学——Chillarege 1992 ODC、MAST、Model-or-Harness;能力边界不对称——SayCan(2022 年就是为这个不对称而生,我们只是反转了方向:学习原语否决规划器,而非规划器被 affordance 接地)。

## 四、杀名单(已判死,不要再翻案)

1. **T1 原表述("第一个把知识状态做成受控变量、第一个对着噪声底解释效应量的具身 harness")**:逐项被拆——PhAIL 在具身域先用了 McNemar+分布方法论,MEMENTO 先把记忆有无做成具身实验条件,2606.15017 先把技能/记忆模块做成带方差附录的受控臂,2602.16666/2605.28840 先把跑间噪声当一等指标。剩下的是特性合取,合取不是发现。只以收窄版活在方法章(见第一节第 4 名)。
2. **T2 的仪器主张("--ban-tools 把工具注册表变成实验变量是新仪器")**:SWE-agent 2024 年、VoLo 在完全相同的具身场景,都先做了。以及"只有消融臂能检测到剪枝"——SAFE/VLA-FAIL 整个子领域就建立在"VLA 静默失败"这个前提上。只保留机理发现(收窄版第 3 名),仪器一个字不许提"首创"。
3. **T5 全部("治理化知识生命周期")**:退休门 ExpeL 2023 年就有(重要性计数删除)、MemoryBank 有衰减、Mem0 把 DELETE 做成一等操作、2607.10113 已把 Prune/Merge/Rerank 写成分类学轴;代码强制种子分离是 Procgen 2019 年的标准基建,resident 会话 + 强制隔离 AHD Agent 已做;run#seq 溯源是标准 MLOps 血统追踪,概念上是 Doyle 1979 的 TMS。"四个对比系统都没有退休"是选基线造出的假空白。除非跑出"消融退休门损失 Δ、协议纪律泄漏 Δ、溯源回滚恢复 R%"三个测量值,否则 T5 的机制只作为 T3/T1 的实施细节各写一段,不成论点。
4. **原始定位("harness 框架是空地")**:ETA 的存在直接证伪。所有对外表述改用收窄版:执行治理与性能脚手架已有人做,**测量与归因层**没有——而且这句话也要靠第二节的三个结果撑,不能裸说。
5. **一切"第一个加误差棒/做统计"口径**:那是 Miller/PhAIL/TRI 已经规定过的卫生标准。我们的说法只能是"仪器改变了结论"(gen-0 的 −6 会被误读、ETA 的 0→1→0 因无噪声底而不可诊断),不能是"我们先做了统计"。
